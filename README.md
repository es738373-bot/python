# Изгиб Питона

Классическая игра «Змейка» на Python и Pygame, написанная на принципах ООП.

## Правила

- Змейка движется по полю 32×24 клетки и управляется стрелками.
- Съеденное яблоко добавляет один сегмент.
- Змейка проходит сквозь стены и появляется с противоположной стороны.
- Столкновение с собой начинает игру заново.
- Esc — выход.

## Запуск

```bash
pip install -r requirements.txt
python the_snake.py
```
